# Data sources: policy and decisions

The live list, with coverage and last-update times, is [data-inventory.md](data-inventory.md). It's generated by `python -m modelroom sources inventory --docs`. This page explains why each source is used, limited or excluded. Checked 2026-11-02.

## Policy

1. Official league sources first, then public downloadable datasets, then permitted public pages. No source needs a paid API key unless no permitted public alternative exists. Where one is needed, it's optional.
2. No bypassing logins, paywalls, CAPTCHAs or access controls. robots.txt, crawl delays and site terms are followed.
3. Raw files are kept exactly as downloaded, in `data/raw/`. Model tables are rebuilt from them into `data/processed/`. Each download records its URL, retrieval time and SHA-256 in the folder's `manifest.json`, and each source's last success or failure is recorded in `data/raw/_state.json`.
4. Before any dataset is used, `python -m modelroom sources validate` checks its columns, coverage, missing values, duplicates and plausibility.
5. Conflicts between sources are reported, not silently overwritten. Official league records win when a conflict has to be settled.
6. Missing values stay missing. A line that isn't available is never shown as 0 and never filled in.

## What the official league sites allow

| Site | robots.txt | Terms of use | Decision |
| --- | --- | --- | --- |
| NBA.com | Allows schedule, game, team and standings pages; disallows `/api/*`; blocks AI crawlers | Terms updated 2026-07-13: NBA Statistics may only be used for news or **private, non-commercial** purposes. They may **not** be used "in connection with any gambling activity (including legal gambling activity)", in commercial products, or in a comprehensive, regularly updated stats database without NBA consent. | **Reference only.** Model Room compares projections with betting lines and is planned as a paid product, so collecting NBA.com data needs a license. |
| cdn.nba.com (data files) | n/a | Direct requests return *Access Denied*; the files load only inside nba.com pages. | **Not used.** Fetching them would mean working around an access control. |
| NFL.com | Permissive | Forbids robots/spiders that "harvest or otherwise collect information … to be used for any commercial purpose". Also forbids using the site to gamble on NFL games. | **Reference only** until licensed. Manual checks are fine. |

## Sources in use

| Source | Why | Notes |
| --- | --- | --- |
| **nflverse** (games.csv, play-by-play, injuries) | Most complete free NFL dataset. CC-BY 4.0. Built from the NFL's own game feeds. | Credit nflverse wherever the data is shown. Play-by-play final scores match games.csv in 973 of 975 recent games; the 2 differences are last-play timing. |
| **hoopR / sportsdataverse** (NBA schedules, team and player box scores) | Complete game-level NBA history with box-score inputs for possessions. | Scraped from ESPN, so ESPN's terms apply to the underlying data. Fine for building and testing; needs a license review before charging subscribers. |
| **Land of Basketball** (results pages) | Independent cross-check of NBA final scores. | Only `/results/` pages, 20 s between requests, never `/box_scores` or player pages (robots.txt). Never republished. First check: all 88 October 2026 games match hoopR, overtime included. |
| **StatsCrew** | Season team totals, for spot checks. | Reference only; robots.txt crawl delay 5 s. Season level, so not used in models. |

## Betting lines

| Source | Status | Why |
| --- | --- | --- |
| nflverse `spread_line` / `total_line` / moneylines | Used for NFL | Free and back to 1999. No sportsbook or timestamp is published, so each line is stored with `captured_at = null` and a note saying so. |
| The Odds API | Optional (`ODDS_API_KEY`) | No permitted public NBA line feed exists, which is why a key is the route here. The free tier is 500 credits a month. Each row records the sportsbook, market and the book's own update time. |
| Manual CSV (`data/manual/<league>_lines.csv`) | Optional fallback | Template: `modeling/templates/lines_template.csv`. Sportsbook, market, line and a timezone-stamped `captured_at` are required. Bad rows are rejected with the reason, never repaired. |
| Sportsbook websites | Not used | Their terms forbid automated access and the pages require location checks. |
| SportsbookReviewsOnline archive | Gone | The archive URL now redirects to an advertising page. |
| FantasyData | Not used | Its odds come through a keyed, paid API. |

Consensus line used by the models: the latest line from each book, then the median across books, along with the number of books and the newest timestamp.

## Licensed official data (for a paid launch)

The leagues license their official data through distributors:

- **NFL:** Genius Sports is the exclusive distributor of official NFL live data and Next Gen Stats to media and betting markets, extended through at least 2027-28 ([Legal Sports Report](https://www.legalsportsreport.com/123307/genius-extends-nfl-betting-data-deal-at-least-five-years/)).
- **NBA:** Sportradar holds the NBA's official data rights under an eight-year deal announced in 2021 that gave the NBA equity in Sportradar ([iGaming Business](https://igamingbusiness.com/sports-betting/nba-to-receive-equity-in-sportradar-with-exclusive-data-deal/)). Sportradar and Genius Sports were both named NBA betting data partners in 2020 ([NBA](https://pr.nba.com/nba-sportradar-genius-sports-group-partnerships)).
- **Licensed resellers** (such as SportsDataIO) sell league data under their own terms.

Ask each one whether a license covers a subscription analytics product that shows betting lines. Pricing is by quote.
